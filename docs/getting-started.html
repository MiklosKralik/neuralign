Getting started

Input data

Pass NeuralignModel a sequence containing one NumPy array, PyTorch tensor, or array-like object per session. Each input must have shape (neurons, time, trials). Sessions may contain different numbers of neurons and trials, but their time dimension must match.

Optional trial labels can be supplied alongside the tensors. Provide one label sequence per session, with one label for each trial: 

from neuralign import NeuralignConfig, NeuralignModel

model = NeuralignModel(
    session_tensors,
    trial_labels=session_labels,
    config=NeuralignConfig(rank=6, seed=42),
)
factors = model.fit("cpu")

Trials can be retained for reconstruction but excluded from alignment with a Boolean trial_mask. Provide one mask per session and one value per trial; True means alignment-excluded and False means alignment-included: 

model = NeuralignModel(
    session_tensors,
    trial_labels=session_labels,
    trial_mask=session_masks,
    config=NeuralignConfig(rank=6, seed=42),
)

In unsupervised mode, masked trials are excluded from the neural and trial-factor averages used to align sessions. In condition-aware mode, they are also excluded from the condition vocabulary, condition centroids, and condition means. They remain in reconstruction and keep their own trial factors. Every session needs an unmasked trial.

Pass "cuda" to fit when a compatible PyTorch CUDA installation is available.

Configuration

NeuralignConfig controls rank, initialization, optimization, loss selection, regularization, non-negativity, progress display, and random seeding. Keyword overrides can also be passed to NeuralignModel; invalid configuration names raise ValueError.

The default loss uses Frobenius reconstruction error. Count-valued data can use the supported Poisson modes through loss_type, optionally together with non_negative=True.

Results

fit returns a NeuralignFactors object containing shared factors and one TensorFactors object per input session. Index the result to access a session, or use its save and adaptation methods to persist a fit or add held-out sessions.

Adapting to held-out sessions

Use partial_fit on fitted factors to estimate only the session-specific factors for new recordings. Shared factors and optional condition prototypes remain frozen, and the original fit is not modified. 

adapted = factors.partial_fit(
	    held_out_tensor,
	    trial_labels=held_out_labels,
	    trial_mask=held_out_mask,
	    device="cpu",
    max_iter=500,
)

held_out_factors = adapted[-1]
adaptation_history = adapted.metadata["adaptations"][-1]

Multiple tensors can be adapted together by supplying one label sequence per tensor. Known labels use the fitted condition prototypes. Unknown labels produce a warning and are excluded; sessions without recognized labels use trial-averaged alignment. Masked trial labels are not used as anchors and are not reported as unknown. Masked trials are still reconstructed and receive trial factors. New tensors must share the fitted time axis, and every session needs an unmasked trial.
