Model and outputs

Neuralign combines a CP tensor reconstruction with a soft PARAFAC2-inspired alignment. Shared temporal factors establish component identity; session-specific neuron and trial factors retain the map to recorded cells and individual trials.

Representations

  • factors.V: shared temporal factors, (time, rank).
  • factors[i].trial_factors: trial expression, (trials, rank).
  • factors[i].neuron_factors: neuron loadings, (neurons, rank).
  • latent_trajectories(): rank-constrained predictions, (trials, time, rank).
  • projected_trajectories(Z): measured activity projected with the session matrix Q.
  • reconstructed_tensor(): fitted activity in the original tensor layout.
  • reconstructed_latent_tensor(): aligned prediction in (latent coordinates, time, trials) layout using w, H, S, V, U.

Selected components

session.reconstructed_tensor(components=2)
session.reconstructed_tensor(components=[0, 2])
session.reconstructed_latent_tensor(components=[0, 2])
session.latent_trajectories(components=[0, 2])

All three methods also accept normalized=False. Set normalized=True to use unit global weights instead of w, without changing stored factors. This retains session gains S and every other factor; it does not impose a unit output norm. Gradients bypass w in this mode.

Indices are zero-based and distinct. Omit components for all components; an empty sequence returns zeros. Selecting n components gives a rank-at-most-n contribution, retaining all output neurons or latent coordinates and preserving dtype, device, and gradients. Selection restricts columns of H, not latent coordinate rows.

Multiplying the latent tensor by orthonormal Q preserves its Frobenius norm, but equals the fitted full reconstruction only when A = Q H diag(S). With soft coupling the two reconstructions measure different quantities. See the source document for formulas and validation guidance.

Interpretation

Use trial factors for trial-to-trial component expression, predicted trajectories for rank-constrained denoising, and projected trajectories when linear neuron or region contributions matter. Components remain subject to permutation, sign and scale conventions; match components before comparing independent fits.

Held-out sessions

partial_fit freezes global weights, temporal factors, mixing geometry and condition prototypes while estimating the factors of new sessions. Joint-fit decoder transfer and prospective held-out-session adaptation are distinct evaluations.
