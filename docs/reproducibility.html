Reproducibility guide

Record the full analysis state

Archive repository commits, the lockfile, hardware and software versions, session inclusion tables, preprocessing, trial masks, complete configuration, model seeds, fitted factors, decoder folds and tidy plotted data.

Validate the scientific unit

Optimization seeds measure fit stability, not biological replication. Use grouped folds for session transfer, preserve negative regression scores, and treat absent regions as unavailable rather than zero activity.

Check model sensitivity

Inspect reconstruction and alignment losses across nearby ranks, match components between initializations, and compare conclusions with hierarchy-preserving nulls. Clearly separate representation fitting from downstream decoder validation.

Persistence

NeuralignFactors.save records exported factors, configuration and metadata. Load only trusted files because persistence uses PyTorch serialization.
